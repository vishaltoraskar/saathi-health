## Run it on your computer

Needs only Node.js (no install step):

```bash
node server.js
```

Then open http://localhost:5500. It works in demo mode with no key. To use real AI, open **Settings** and paste a free Google Gemini API key (it is saved only in your browser, never in this repository).
